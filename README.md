# CerviCare

A clickable web version of the CerviCare app: learn about cervical cancer, break the stigma, and track HPV vaccinations and screenings.

This is a front end only. Sign up, login, OTP and records are not connected to a backend yet.

## Run it
Open `index.html` through any static web server, or publish the folder with GitHub Pages (Settings, Pages, Deploy from a branch, `main`, `/ (root)`).

On a phone, open the published link and choose "Add to Home Screen" to install it like an app.
